# Face-Lock Image Generator

เว็บสร้างภาพจากรูปอ้างอิงใบหน้า + Prompt  
เหมาะสำหรับสร้างภาพนางแบบ/พรีเซนเตอร์/คอนเทนต์โฆษณา โดยเจนรอบละ 5 ภาพ และพยายามคงใบหน้าเดิมให้มากที่สุด

> หมายเหตุแบบพูดตรง ๆ: ระบบนี้ล็อกหน้าโดยใช้ reference image + `input_fidelity=high` + prompt บังคับ identity แต่ AI ยังไม่สามารถรับประกันว่าใบหน้าจะเหมือน 100% ทุกพิกเซลทุกครั้งได้ ถ้าต้องการนิ่งระดับใช้งานหนัก ควรต่อยอดด้วย LoRA / IP-Adapter / Face Similarity Check

## วิธีใช้งาน

### 1) ติดตั้ง Node.js
แนะนำ Node.js 20 ขึ้นไป

### 2) แตกไฟล์ zip แล้วเปิด Terminal ในโฟลเดอร์นี้

```bash
npm install
```

### 3) ตั้งค่า API key

คัดลอกไฟล์ `.env.local.example` แล้วเปลี่ยนชื่อเป็น `.env.local`

```bash
cp .env.local.example .env.local
```

จากนั้นเปิดไฟล์ `.env.local` แล้วใส่ OpenAI API key:

```env
OPENAI_API_KEY=sk-xxxxxxxx
IMAGE_MODEL=gpt-image-1
```

### 4) รันเว็บ

```bash
npm run dev
```

เปิดเว็บที่:

```text
http://localhost:3000
```

## ฟีเจอร์ที่มี

- อัปโหลดรูปอ้างอิงได้หลายรูป
- ใส่ Prompt ภาษาไทย/อังกฤษได้
- เจนภาพรอบละ 5 ภาพเป็นค่าเริ่มต้น
- เลือกขนาดภาพ 1:1 / 9:16 / 16:9
- เลือกระดับล็อกหน้า ปกติ / แน่น / แน่นมาก
- ดาวน์โหลดภาพทีละรูป หรือดาวน์โหลดทั้งหมดเป็น ZIP
- API key อยู่ฝั่ง server ไม่ถูกเปิดใน browser

## คำแนะนำเพื่อให้หน้าไม่เพี้ยน

1. ใช้รูป reference ที่หน้าชัด แสงดี ไม่ใส่แว่นดำ
2. ใส่ reference หลายมุม 3–8 รูป จะดีกว่ารูปเดียว
3. อย่าเปลี่ยนทรงผม/อายุ/เชื้อชาติ/โครงหน้าใน prompt
4. ถ้าอยากเปลี่ยนชุด ให้สั่งเปลี่ยนแค่เสื้อผ้า ฉาก และท่า
5. ถ้าหน้าเพี้ยน ให้ลดความแฟนตาซีของ prompt และใช้ภาพหน้าตรงเพิ่ม

## ใช้ให้ถูกสิทธิ์

ใช้เฉพาะรูปของตัวเอง หรือรูปที่ได้รับอนุญาตจากเจ้าของภาพเท่านั้น ห้ามใช้ปลอมตัว หลอกลวง หรือแอบอ้างเป็นบุคคลอื่น


## เวอร์ชันแชร์ให้คนอื่นใช้

เวอร์ชันนี้เพิ่ม `SHARE_PASSWORD` แล้ว  
ถ้าตั้งค่าไว้ ผู้ใช้ต้องใส่รหัสก่อนกด Generate

ดูวิธีเอาขึ้นเว็บในไฟล์:

```text
DEPLOY.md
```


## เวอร์ชันเว็บแอพ / PWA

เวอร์ชันนี้เพิ่มไฟล์ `manifest.json` และ icon แล้ว  
หลัง deploy ขึ้นเว็บ HTTPS เช่น Vercel ผู้ใช้สามารถเปิดลิงก์แล้วติดตั้งเป็นแอพบนมือถือหรือคอมได้

ดูคู่มือแบบไม่ต้องติดตั้งในเครื่องที่ไฟล์:

```text
SETUP_NO_INSTALL.md
```
